# Policy Checklist

## Owned by This Skill

- No `latest`
- No npm-style ranges
- No prereleases by default
- The shared `minimum_release_age` guard and its exception criteria
- When to use trust, safe mode, and paranoid mode
- Severity criteria (`info`, `warning`, `policy-error`, `error`)

## Not Owned by This Skill

- Java vendor naming rules
- Gradle major floor
- Python selector floor
- uv selector floor
- Lockfile creation and platform operations (`mise-lock`)
- CI install flow (`mise-ci`)
